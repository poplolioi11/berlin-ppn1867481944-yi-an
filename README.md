# 醫案（1920–1922 年，柏林國家圖書館 Slg. Unschuld 8368，病例索引） / Yi an [Medical case histories]: Case Locator Dataset

《醫案》是柏林國家圖書館所藏約 1920–1922 年的漢文醫案手稿，含臨診症候、地名旁註與抄記。卷內見浦東、小西門、南昌街等地名，並有 1921 年 7 月 2 日抄記。此索引將可辨的病例題頭、地名與日期連回原圖，供查訪近代漢文醫案與城市醫療史。

Yi an is a Chinese medical case notebook dated 1920–1922 in the Staatsbibliothek zu Berlin. It contains consultation notes, place labels and dated copying inscriptions, including one dated 2 July 1921. This source-linked finding aid supports navigation to selected case headings, place names and copying dates.

## 方法與覆核 / Methods and review

AI 初讀固定影像後，建立可辨的病例題頭、地名與抄記日期索引。題頭與地名是選錄。研究者可沿館方連結核其他文字及草寫。人類全文雙校、專家審定、同儕審查及準確率量測尚未進行。實際模型識別與使用量未知。此資料公開供比對與引用，處理程式及影像另存。

An AI assistant extracted selected factual headings, place labels and copying dates from the fixed scans. Only selected short factual labels are included. The library images provide the complete manuscript witness. Human proofreading, expert review, peer review and accuracy measurement are pending. The actual model identifiers and usage are unknown.
